關於我

成就感來自於學習

程式起源從我小六開始，為了解決家裡老電腦跑不動遊戲，
自己上網找了很多能最佳化遊戲的方法，不斷的嘗試。
從晚上八點開始不停止的爬文做功課，在凌晨五點的早上
終於被我完成人生中第一個程式碼。

cmd.exe nba2k_optimize.bat
C:\Users\tian> nba2k_optimize.bat
@echo off
:: 開始效能電源模式
powercfg -duplicatescheme e9a42b02-d5df-448d-aa00-03f14749eb61
powercfg /setactive e9a42b02-d5df-448d-aa00-03f14749eb61

:: 清除系統暫存與 Cache
del /q /f /s "%TEMP%\*.*"
del /q /f /s "C:\Windows\Temp\*.*"
del /q /s /f "%AppData%\2K Sports\NBA 2K11\Cache\*.*"

:: 啟動 nba2k11.exe
start /high "" "nba2k11.exe"
exit
[OK] Power plan optimized.
[OK] Temporary files and cache cleared.
[RUN] nba2k11.exe started with high priority.
C:\Users\tian>_

當腳本執行、遊戲再次開啟後，看著 FPS 從 30 左右提升到 50+，
那種「僅僅幾行程式碼就能讓體驗大幅改善」的衝擊感，
加上能馬上看到成果的回饋，讓我獲得了前所未有的成就感。
自此，我便慢慢踏入了 Coding 的這條「不歸路」，
這份對技術的純粹熱忱延續至今。
